# Contributing

Contributions are welcome.

## Rules

1. Keep the CLI dependency footprint small.
2. Add tests for new rules.
3. Avoid false positives where possible.
4. Document rule severity and behavior.
5. Do not commit secrets or real tokens.

## Development

```bash
npm install
npm test
```

## Pull requests

Use clear commit messages. Explain the rule, the risk, and the detection logic.
